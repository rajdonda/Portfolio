# Donda Raj - Portfolio Website

A modern, responsive portfolio website showcasing my skills, projects, and experience as a Full-Stack Developer (MERN) & WordPress Developer.

## 🚀 Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean and professional design with smooth animations
- **Portfolio Showcase**: Display of various projects including web apps, dashboards, and WordPress sites
- **Resume Section**: Educational background and professional experience
- **Contact Form**: Easy way for potential clients to get in touch
- **Skills Display**: Comprehensive overview of technical skills

## 🛠️ Technologies Used

- HTML5
- CSS3 / SCSS
- Bootstrap 4
- JavaScript (ES6+)
- jQuery
- Isotope.js (for portfolio filtering)
- Various CSS animations and effects

## 📦 Installation

This is a static website. Simply clone or download the repository and open `index.html` in your browser.

```bash
git clone https://github.com/yourusername/raj-donda-portfolio.git
cd raj-donda-portfolio
# Open index.html in your browser
```

## 🔧 Deployment

This website is deployed using GitHub Pages. To deploy:

1. Push your code to GitHub
2. Go to repository Settings > Pages
3. Select the branch (usually `main` or `master`)
4. Select the folder (usually `/ (root)`)
5. Click Save

Your site will be live at: `https://yourusername.github.io/raj-donda-portfolio/`

## 📝 Customization

- Edit `index.html` to update content
- Modify CSS files in `css/` directory or SCSS files in `scss/` directory
- Update images in `images/` directory
- Replace resume PDF in `images/` folder
